# nk-php-legacy

NodeKeeper (NK) 维护的 **PHP 旧版本安全修复源码**。

PHP 官方已经不再为这些版本发布修复版(EOL)。当官方出了严重安全漏洞、但没有给某个旧版本出修复时,
NK 在这里按版本做**最小语义回移植**,发布带补丁的源码包,NK 安装 PHP 时从本仓库的 Release 下载。

## 范围

| 版本 | 来源 |
|---|---|
| 5.2 – 7.3 | NK 自行回移植(官方未提供修复) |
| 7.4 / 8.0 / 8.1 | 以 PHP 官方安全回移植分支为准(官方只给分支、不发版),NK 打成可下载的源码包 |
| 8.2 及以上 | **不放在这里**,直接使用 php.net 官方修复版 |

**原则:官方仍在维护的版本一律用官方版;官方以后若为某个旧版本发布修复,改回用官方版,本仓库对应版本停止更新。**

## 布局

- 分支 `nk/PHP-<主.次>`:以官方最后一个发行版标签为起点,每个安全修复一个独立提交,提交信息写明 CVE、对应的上游提交、改动理由。
- 标签 `php-<版本>-nk<N>`(如 `php-5.6.40-nk1`):每次修复发布一个新标签,并在 Release 里附源码包与 `SHA256SUMS`。
- 每个版本的分析、测试证据与状态见 NodeKeeper 主仓库 `security/` 目录下对应的安全事件文件夹。

## 安全说明

这些版本已经 EOL。本仓库只修复列出的漏洞,**不代表这些版本没有其他已知风险**。能升级到官方仍在维护的版本时,请优先升级。
